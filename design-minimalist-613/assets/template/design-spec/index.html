02

雾感八色

低色度主题共享同一视觉重量；切色时，范围、结果、标签与连线同步更新。

P100 / 浅底
P300 / 反馈

组件使用语义色阶；重色只服务于小标签与关键焦点。

03

层级 × 流程

先按可见量感分类，再对齐实体内容；虚线仅表达语义范围。

L1 浅底line / 范围surface / 卡片mass / 结果反馈

实体卡片与结果层共享可见边界；Loop 与主内容保留白色隔离，视觉量感低于主系统。

04

先定信息主角，再分配面积；直角、无阴影、无渐变，填色与边线二选一。

05

先选择 canonical canvas，再排版与导出；预览只做整体等比缩放。

06

Template 包含什么

规则负责稳定生成，项目实例负责复用结构，预览负责理解设计；三者不混在同一层维护。

RULES通用规范 + 项目 Presets

通用 Token、画板合同与跨项目方法放在 GENERAL；尺寸、媒介优先级和特殊例外放在 PROJECTS。

SOURCE项目 HTML 源文件

每个项目保留确认过的 example.html，复用真实结构、排版与组件关系，不从零猜测。

ASSETS项目专属资产

头像、照片、插画及其他只在特定项目召回的资源，跟随对应项目独立维护。

PREVIEW规范可视化 + 固定画板 PDF

HTML 负责连续浏览；PDF 默认以 1440 × 810 固定画板、一模块一页输出，特殊媒介再覆盖尺寸。

01 读取 GENERAL02 选择 PROJECT PRESET03 复用 HTML + ASSETS04 固定画板导出

默认策略：浏览页面可流式响应；一旦进入 PDF、PPT、海报或截图交付，就先锁定 canonical canvas。特殊需求只覆盖画板尺寸，不重写内部规则。
