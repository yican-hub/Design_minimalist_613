# resume-minimal｜Canvas Contract

## 1. 单页 Canonical 画板

- 固定为 **单页 595 × 837 A4**；所有尺寸、边距、文本区域和溢出判断均在该坐标系中完成
- 页面按 4px 网格填充，但任何内容不得越过安全边界
- 内容紧张时优先调整层级间距比例、删除无效留白与精简重复文案，不使用响应式重排

## 2. HTML 预览合同

HTML 只允许在 canonical DOM 外层整体等比缩放：

```text
scale = min(containerW / 595, containerH / 837)
transform-origin = top left
```

内部禁止媒体查询重排、节点换行重组、局部缩放或按容器宽度改写尺寸；PDF 从同一份未缩放 canonical DOM 导出

## 3. 层级系统

字体、段距和分割线组成同一套层级系统。层级切换时必须同时联动字号、字重、行高与 after spacing，不能只改字号：

| 层级 | 语义 | resume-minimal 紧凑 Token |
|---|---|---|
| L1 | section 标题 | 8.90pt / 600 |
| L2 | 公司、机构或经历标题 | 7.35pt / 600 |
| L3 | 所有项目标题 | 6.82pt / 600 |
| L4 | 正文、技能项目描述 | 6.12pt / 325 |
| L5 | 日期、地点等 meta | 5.72pt / 400 |

以上字号与字重是 `resume-minimal` 已验证 preset，不是通用规则，不得写入 `GENERAL.md`

- 所有项目标题统一使用 L3，不因标题长度、所在栏位或页面位置单独缩放
- 正文和技能项目描述统一使用 L4
- 标签只按源文档标记加粗
- 公司行只强调源文档指定的小部门，不整行无差别加粗

## 4. 分割线层级

- section：约 `#8F8F8F / 0.5pt`
- 经历：约 `#C2C2C2 / 0.4pt`
- 项目：约 `#E2E2E2 / 0.35pt`

分割线由深到浅辅助 L1/L2/L3 层级，不替代字号、字重、行高和段距

## 5. 富文本逐项映射

飞书源文档标记必须逐项保真，不新增、不遗漏，也不把一种强调替换成另一种：

| 源标记 | HTML/PDF 映射 | 字重 |
|---|---|---|
| `<u>` | 仅下划线 | 400 |
| `<em><u>` | 斜体 + 下划线 | 400 |
| `<b><em><u>` | 加粗 + 斜体 + 下划线 | 600 |
| `<b>` | 仅加粗 | 600 |

## 6. 头像稳定资源

- 用户提供新头像时，将最新上传图复制为项目稳定资源 `assets/profile-avatar.png`
- 使用固定照片框、`object-fit: cover`，按构图校准 `object-position`；校准裁切而不移动照片框
- 示例文案保持匿名，不写入姓名、联系方式或业务数据

## 7. 高清图片 PDF

当目标是最大程度还原 HTML，生成图片化 PDF：

1. 从未缩放的 595 × 837 canonical DOM 渲染
2. 至少使用 5× / 360DPI、无损 PNG；对应图像尺寸为 **2975 × 4185**
3. 将图像封装为单页 A4，不得产生额外页、缩放漂移或随机分页
4. 图片 PDF 不可检索；需要检索时保留文本版 PDF
5. 用户只要单一最终交付时，默认交付 **HTML 链接 + 一份高清图片 PDF**

每次导出必须执行：

- `pdfinfo`：验证页数为 1、页面尺寸为 A4
- `pdfimages`：验证嵌入图像及其分辨率达到要求
- `html_vision`：校验页面构图、文本溢出、安全边界、换行和视觉一致性

## 8. 句末标点与事实字段

- 句末无句号是可选风格，不对所有简历强制执行
- 只有用户明确要求时，才同步修改源文档、HTML、PDF，并对中文句号 `。` 做计数校验
- 姓名、联系方式等事实字段更新后必须重新生成 PDF，不得只改 HTML

## 9. 验收清单

- 画板固定 595 × 837，PDF 仅一页；HTML 只在外层等比缩放
- 内容落在 4px 网格与安全边界内，内部无响应式重排
- L1–L5 同时联动字号、字重、行高、after spacing；所有项目标题统一使用 L3
- 正文和技能项目描述统一使用 L4；标签、部门和富文本只按源文档映射
- section、经历、项目分割线形成深浅层级
- 头像来自稳定资源，固定框使用 cover 并校准 object-position
- 图片 PDF 为无损 PNG、至少 5× / 360DPI、2975 × 4185，并通过 `pdfinfo`、`pdfimages` 与 `html_vision` 校验
- 若明确要求句末无句号，三种载体同步且计数为 0
- 事实字段变化后已重新生成 PDF
